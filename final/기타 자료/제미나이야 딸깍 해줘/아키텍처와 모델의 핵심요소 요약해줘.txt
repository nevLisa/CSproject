보고서의 '시스템 설계' 및 '구현 방법' 섹션에 바로 복사해서 붙여넣기 좋도록, 가독성을 최우선으로 고려하여 정리했습니다.

[시스템 아키텍처 및 구현 방법]
1. 전체 시스템 아키텍처
본 시스템은 AI 백엔드와 데스크톱 GUI가 결합된 End-to-End 약초 분류 프로그램입니다. 데이터 파이프라인부터 학습, 추론, 시각화까지의 구조는 다음과 같습니다.

데이터 모듈 (Data Manager & Dataset): 원본 이미지와 JSON 라벨을 매칭하여 데이터프레임화하고, 원본 비율을 유지하는 전처리(Padding & Resize)를 수행합니다.

AI 학습 모듈 (Train): ResNet50 백본을 활용한 멀티태스크 학습을 통해 식물 종류와 부위를 동시에 분류합니다.

디코더 모듈 (Utilities): AI의 수치적 출력값(Logits)을 인간이 이해 가능한 약초 명칭 및 효능 정보로 복원(Decoding)합니다.

통합 GUI 모듈 (Main): PyQt5를 사용하여 사용자 경험(UX)을 고려한 화면 구성 및 실시간 추론 결과 시각화를 구현합니다.

2. 핵심 모델 설계 (Multi-Task Learning)
본 프로젝트는 효율성과 성능을 극대화하기 위해 멀티태스크 러닝(Multi-Task Learning) 구조를 채택하였습니다.

Backbone Network: 검증된 모델인 ResNet50을 사용하여 이미지의 공통 특징(Texture, Shape 등)을 효율적으로 추출합니다.

Multi-Head 구조: 추출된 특징은 두 개의 개별 완전연결계층(FC Layer)으로 분기됩니다.

Head 1 (fc_plant): 식물의 종(Species) 분류

Head 2 (fc_part): 식물의 부위(Plant Part) 분류

설계 강점: 각각 별도의 모델을 운용하는 것 대비 연산량이 절감되며, 종류와 부위 간의 상호 연관 정보를 함께 학습함으로써 일반화 성능이 향상됩니다.

3. 데이터 파이프라인 및 전처리
동적 라벨링: 폴더 구조와 JSON 데이터를 스캔하여 메타데이터를 자동 구성합니다.

데이터 균형 유지: stratify 기법을 적용한 계층적 데이터 분할로, 특정 클래스에 편향되지 않는 학습셋을 구축했습니다.

입력 데이터 보정: Resize 과정에서 이미지 왜곡을 방지하고자 224x224 규격에 비율 유지 패딩(Padding)을 적용하여 모델 입력값의 정확도를 확보했습니다.

4. 학습 및 최적화 전략
데이터 증강: Random Rotation, Horizontal Flip, Color Jitter 등을 통해 다양한 실물 촬영 환경에 대한 강건성(Robustness)을 확보했습니다.

Multi-Loss 최적화: 종류 예측 오차와 부위 예측 오차를 합산하여 모델을 학습시킵니다.

Optimizer: AdamW와 CosineAnnealingLR 스케줄러를 조합하여 손실값의 발산을 방지하고, 최적 가중치를 빠르게 수렴하도록 설계했습니다.

5. 프론트엔드 및 시스템 통합
화면 전환 아키텍처: QStackedWidget을 활용하여 사용자 메뉴 이동을 매끄럽게 처리하는 SPA(Single Page Application) 방식을 구현했습니다.

실시간 추론 시각화:

모델 입력 시 정규화(Normalization) 단계를 학습 과정과 동일하게 설계하여 추론 신뢰도를 확보했습니다.

예측 결과를 PlantLabelDecoder로 실시간 처리하고, OpenCV를 통해 예측 신뢰도를 시각화한 막대그래프를 GUI에 동적으로 출력하여 직관성을 높였습니다.
